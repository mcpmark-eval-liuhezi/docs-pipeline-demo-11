# docs-pipeline-demo

This repository is a clean sandbox for rehearsing our docs-pipeline demo ahead of the quarterly review. It holds a short demo brief, a pre-demo checklist, and a minimal GitHub Actions workflow so we can walk through the release-to-docs path end to end without touching any production content.

## What's here

- `docs/demo-brief.md` — a two-sentence introduction to the demo.
- `notes/scratch-notes.md` — a placeholder scratch notes file (to be tidied up).
- `.github/workflows/ci.yml` — a minimal CI workflow that echoes a hello line on every push.
